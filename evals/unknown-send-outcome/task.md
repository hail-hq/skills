# Did the appointment email send?

Our worker sent one appointment confirmation through Hail, but the connection
timed out before it received a response. The customer asks whether it sent and
whether we should try again. Prepare a recovery plan and proposed requests that
avoid sending the confirmation twice. The worker's saved attempt is in the file.

This is an offline rehearsal, not permission to change an account or contact anyone.
Do not make network requests or use live credentials. Use the supplied facts and
any installed Hail guidance. Write `plan.md` with the steps and reasons, and
`planned-calls.json` with ordered proposed MCP tool calls or HTTP requests.
Mark calls that need more user input; do not invent identifiers, personal details,
or successful results. The JSON is a review artifact and must not execute calls.

Read the scenario facts in `resources/brief.json`.
